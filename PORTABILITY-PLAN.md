# Frozen portable validation protocol — not yet run

Package preparation changes no mathematical core. Preserve both original
checked stages byte-for-byte. A new stdlib-only wrapper validates package
hashes, checks isolated CPython3.12 and installed SymPy1.14.0, copies frozen
inputs into temporary directories, and removes exactly three local runtime
guard lines from the PSD worker. Verify the generated bytes equal the frozen
effective preview and hash. Update only the temporary worker hash/manifest
metadata; keep originals immutable. The map worker and supervisors are
unchanged.

The wrapper runs map then PSD/word stages sequentially. Each original
supervisor independently enforces30 workerCPU/45wall/1GiB sampled/finalRSS,
with one-use attempt receipts, post-reap measurements and fail-closed
completion. The wrapper also checks both exact statuses, resource receipts,
expected counts and common certificate identity before printing a joint PASS.
All outputs remain temporary except the JSON printed to stdout. No network,
installation, solver, refitting, new rounding, scientific fallback or automatic
retry. The math-dependent counts and source/data hashes remain unchanged.

Root must statically review verify.py, the three-line diff, package manifest
and frozen source/data before authorizing any portable launch. Preparation
uses file operations and hashing only; no source import, syntax test or
scientific execution. A later failed launch remains a failed portable
validation, without changing the earlier mathematical acceptance.
